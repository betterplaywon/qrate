# 티스토리 발행 파이프라인

티스토리 오픈 API는 2024-02에 종료됐다. 그래서 발행은 Playwright가 실제 브라우저를
조작하는 방식이며, 로그인 세션은 `scripts/blog/.auth/`에 보존된다(**.gitignore에 포함 —
이 폴더에는 로그인 쿠키가 들어 있으므로 절대 커밋·공유 금지**).

## 1회 준비

```bash
pnpm install
pnpm --filter @qrate/blog-tools exec playwright install chromium
```

## 쓰는 흐름 (주 1회 권장)

```bash
# 1) 초안 생성 — "문제→결정→트레이드오프→배운 것" 뼈대가 들어 있다
pnpm blog:new "AI 상담 위젯 1주차 — CI 게이트를 코드보다 먼저 세운 이유"

# 2) docs/blog/drafts/ 에서 초안 작성 (면접 질문 답변을 글로 옮기면 그게 곧 초안)
#    docs/blog/는 .gitignore 대상이다. 글은 초안이든 발행본이든 레포에 올리지 않는다.

# 3) 임시저장(기본) — 티스토리 에디터에서 눈으로 확인 후 발행해도 된다
pnpm blog:publish docs/blog/drafts/2026-11-05-....md

# 4) 바로 공개 발행
pnpm blog:publish docs/blog/drafts/2026-11-05-....md --go
```

첫 실행 시 브라우저 창이 열리면 카카오 로그인을 직접 완료한다(최대 5분 대기).
이후 실행부터는 저장된 세션으로 자동 진행된다.

## 주의

- 항상 창이 보이는 모드(headful)로 돈다. 내 계정으로 뭘 하는지 눈으로 확인하기 위함.
- 캡차·2단계 인증·일일 발행 한도 안내가 뜨면 스크립트는 우회하지 않는다. 직접 처리할 것.
- 티스토리 에디터 DOM이 바뀌면 `src/publish.ts` 상단 `SEL` 상수만 고치면 된다.
- 자동 발행은 "작성을 대신"하는 게 아니라 "업로드 반복 작업 제거"가 목적이다.
  글 내용은 본인이 쓴다 — 블로그는 면접에서 검증되는 산출물이다.
