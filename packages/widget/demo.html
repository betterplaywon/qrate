가상의 고객 사이트

이 페이지의 전역 CSS는 모든 글자를 빨간 serif로 만든다. 그런데도 우하단 런처가 멀쩡하다면 Shadow DOM 격리가, 대화창이 뜬다면 iframe 격리와 허용 사이트 검사(CSP frame-ancestors)가 작동하는 것이다.

실행 순서: pnpm dev(서버) → pnpm --filter @qrate/widget build → pnpm --filter @qrate/widget demo → http://localhost:5173/demo.html. 파일로 직접 열면(file://) 오리진이 null이라 대화창이 막힌다.
